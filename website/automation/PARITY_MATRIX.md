# Parity Matrix: SSMI Website Conversion (Flutter vs React)

This matrix tracks functional, visual, and responsive parity specifically between the legacy Flutter source (`flutter-website/`) and the React implementation (`website/`) across all 48 routed pages.

> [!NOTE]
> This document is strictly the **Flutter-versus-React Public Website** comparison baseline. It is not a feature plan for the Admin CMS. The Admin CMS feature plan and cross-surface contracts are governed by [`MASTER_PLAN.md`](./MASTER_PLAN.md) and [`FEATURES.md`](./FEATURES.md).

---

## Acceptance Criteria & Evaluation Standards

> [!IMPORTANT]
> **Visual Fidelity Objective (~98% Target):**
> Visual parity cannot be certified by static code inspection alone. The agreed target of approximately 98% visual fidelity is an acceptance objective subject to comparative screenshots and user review.
> 
> **Status Classifications:**
> - **Functional Parity:** `converted and evidenced` | `partial` | `not started` | `intent unclear` | `needs runtime/user verification`
> - **Visual Parity:** `observed` | `not compared` | `needs my review`
> - **Responsive Parity:** `observed` | `not compared` | `needs my review`
> 
> **Required Viewport Verification Widths:**
> `375px` (mobile), `478px` (phone upper), `479px` (tablet lower), `767px` (tablet landscape lower), `990px` (tablet landscape upper), `991px` (desktop lower), `1280px` (desktop standard), `1440px` (desktop wide).
